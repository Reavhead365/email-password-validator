# Email & Password Validator

A beginner-friendly web project built with **HTML, CSS, and JavaScript** to validate email addresses and passwords using **Regular Expressions (Regex)** and DOM manipulation.

This project was created as part of my JavaScript learning journey to strengthen my understanding of form handling, validation, DOM manipulation, and basic JavaScript logic.

## ✨ Features

* Email format validation
* Password validation using Regex
* Minimum password length validation
* Uppercase and lowercase character validation
* Number and special character validation
* Real-time error and success messages
* Clean and responsive user interface
* Beginner-friendly code structure

## 🛠️ Technologies Used

* **HTML5** — Form structure and semantic markup
* **CSS3** — Styling and responsive layout
* **JavaScript** — Form handling, validation, and DOM manipulation
* **Regex** — Email and password pattern validation

## 🔐 Validation Rules

### Email

The email validator checks whether the entered email follows a valid email format.

Example:

```text
example@gmail.com
```

### Password

The password validator checks for:

* At least 8 characters
* At least one uppercase letter
* At least one lowercase letter
* At least one number
* At least one special character

Example:

```text
Hadia@123
```
